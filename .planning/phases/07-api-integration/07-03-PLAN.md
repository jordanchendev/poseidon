1. `@celery_app.task(name="poseidon.workers.cpu_tasks.run_backtest_task", bind=True, max_retries=0)`
   ```python
   def run_backtest_task(self, strategy_id: str, start_date: str | None = None,
                         end_date: str | None = None, initial_capital: float = 1_000_000.0) -> dict:
   ```
   - Open DB session via `SessionLocal()`
   - Query `StrategyRecord` by `strategy_id` UUID, raise ValueError if not found
   - Reconstruct strategy object from StrategyRecord:
     - If strategy_type == "rule": `RuleStrategy(config=record.config, strategy_id=record.id)`
     - If strategy_type == "model": requires loading model from ModelVersion -- for now raise NotImplementedError("Model backtest via API not yet supported") as it requires GPU model loading
   - Load OHLCV data via `read_ohlcv(session, record.symbol, record.market, record.interval, start_date, end_date)`
   - Create `FeatureEngine()`, `RiskEngine()`, `CostModel` (from `COST_MODELS.get(record.market, CostModel())`)
   - Create `BacktestRunner(strategy, feature_engine, risk_engine, cost_model, initial_capital)`
   - Run: `result = runner.run(ohlcv_df)`
   - Persist: Create `BacktestRepository(session)` and call `save_result(config, result, portfolio.trades, portfolio.equity_curve)`
     - Note: BacktestResult already contains trades as dicts. The repository expects TradeRecord objects. Bridge this by using the runner's portfolio directly or by creating BacktestRecord manually:
       - Create `BacktestRecord(id=result.backtest_id, strategy_id=uuid.UUID(strategy_id), strategy_type=record.strategy_type, symbol=record.symbol, market=record.market, interval=record.interval, config=config_dict, metrics=result.metrics, status=result.status, error_message=result.error_message)`
       - Add to session, commit
   - Return `{"backtest_id": str(result.backtest_id), "status": result.status, "trade_count": result.trade_count}`
   - On exception: create BacktestRecord with status="failed", error_message=str(exc), commit, then re-raise
