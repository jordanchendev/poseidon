1. Rewrite `src/poseidon/api/health.py` to report comprehensive system status:
   - Keep `router = APIRouter()`
   - Keep `@router.get("/health")` -- same path, same unauthenticated access
   - Response structure:
     ```python
     {
       "status": "ok" | "degraded",
       "components": {
         "database": "ok" | "error: ...",
         "redis": "ok" | "error: ...",
         "celery": {
           "active_tasks": int,
           "reserved_tasks": int
         } | "error: ...",
         "gpu": {
           "available": bool,
           "free_mb": int | None,
           "total_mb": int | None
         },
         "data_freshness": {
           "latest_ohlcv": "ISO datetime string" | null
         }
       }
     }
     ```
   - Implementation (follow the pattern from 07-RESEARCH.md verified code example):
     a. **Database check**: `SessionLocal()`, execute `select(func.now())`, catch Exception
     b. **Data freshness**: Query `select(func.max(OHLCV.time))` from the same session, format as ISO string
     c. **Redis check**: `redis.from_url(settings.redis_url)`, call `r.ping()`, catch Exception
     d. **Celery queue lengths**: `celery_app.control.inspect(timeout=2.0)`, get `.active()` and `.reserved()`, sum task counts. Catch Exception. Use timeout to prevent blocking.
     e. **GPU status**: `try: import torch; if torch.cuda.is_available(): free, total = torch.cuda.mem_get_info()` -- wrap in try/except ImportError since torch may not be installed in the API container (it's in the GPU worker only). If ImportError, report `{"available": False, "note": "torch not installed"}`.
     f. **Overall status**: If any component value is a string starting with "error", set status to "degraded". Otherwise "ok".
   - Import `redis` (the `redis` package is already installed -- it's the Celery broker dependency)
   - Import `func, select` from `sqlalchemy`
   - Import `SessionLocal` from `poseidon.models.base`
   - Import `OHLCV` from `poseidon.models.ohlcv`
   - Import `celery_app` from `poseidon.workers.celery_app`
   - Import `settings` from `poseidon.core.config`
   - Close the DB session in a finally block
