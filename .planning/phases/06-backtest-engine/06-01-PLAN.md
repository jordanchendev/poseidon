    **1. Create `src/poseidon/backtest/cost_model.py`:**

    Define a frozen dataclass `CostModel` with fields: `market: str`, `buy_commission_rate: float`, `sell_commission_rate: float`, `tax_rate: float`, `slippage_pct: float`, `slippage_ticks: float`, `description: str = ""`.

    Create `COST_MODELS: dict[str, CostModel]` with 7 entries per the RESEARCH.md Pattern 2 (exact fee rates from design spec):
    - `tw_stock`: commission 0.001425 both sides, tax 0.003, slippage_ticks 1.0
    - `tw_stock_etf`: same commission, tax 0.001
    - `tw_stock_daytrade`: same commission, tax 0.0015
    - `tw_futures`: commission 0.0, tax 0.00002, slippage_ticks 1.0
    - `us_stock`: commission 0.0, tax 0.0, slippage_ticks 0.01
    - `crypto_spot`: commission 0.001 both sides, slippage_pct 0.0005
    - `crypto_perp`: buy 0.0002, sell 0.0005, slippage_pct 0.0005

    Add helper `def get_cost_model(market: str) -> CostModel` that looks up COST_MODELS, raises `ValueError` for unknown markets.

    **2. Create `src/poseidon/backtest/portfolio.py`:**

    Class `BacktestPortfolio`:
    - `__init__(self, initial_capital: float, cost_model: CostModel)`
    - Properties: `cash`, `equity`, `positions: dict[str, dict]` (keyed by symbol, value has side/quantity/entry_price/entry_time)
    - `equity_curve: list[tuple[datetime, float, float]]` — (time, equity, drawdown)
    - `trades: list[TradeRecord]` — completed round-trip trades

    Define `@dataclass class TradeRecord` with: symbol, action, entry_time, exit_time (optional), entry_price, exit_price (optional), quantity, pnl (optional), fees, metadata (dict).

    `execute_fill(self, signal: Signal, bar: pd.Series) -> TradeRecord | None`:
    - Get fill price from `bar["close"]`
    - Apply slippage: LONG -> price * (1 + slippage_pct), SHORT/CLOSE -> price * (1 - slippage_pct)
    - Compute fees: buy side = trade_value * buy_commission_rate; sell side = trade_value * (sell_commission_rate + tax_rate)
    - For LONG: open new position, deduct cash by (trade_value + fees)
    - For CLOSE: close existing position, add cash by (trade_value - fees), compute PnL
    - Return TradeRecord

    `record_equity_point(self, time: datetime, current_price: float)`:
    - Compute mark-to-market equity = cash + sum(position_value at current_price)
    - Compute drawdown = (peak_equity - current_equity) / peak_equity
    - Append to equity_curve

    **3. Create `src/poseidon/backtest/metrics.py`:**

    `def compute_metrics(equity_series: pd.Series, trades: list[TradeRecord]) -> dict`:
    - Follow the exact formula from RESEARCH.md: total_return, annualized_return, sharpe_ratio (rf=0, * sqrt(252)), max_drawdown (vectorized cummax), calmar_ratio, win_rate, profit_factor, avg_win, avg_loss, trade_count.
    - Handle edge cases: empty trades, zero std deviation, zero max_drawdown.

    **4. Create `src/poseidon/models/backtest.py`:**

    Three ORM classes inheriting from `Base`:

    `BacktestRecord` (__tablename__ = "backtests"):
    - id: UUID PK with server_default gen_random_uuid()
    - strategy_id: UUID nullable
    - strategy_type: String(16) not null
    - symbol: String(32) not null
    - market: String(32) not null
    - interval: String(8) not null, server_default "1d"
    - config: JSONB not null
    - metrics: JSONB nullable
    - walk_forward: JSONB nullable
    - status: String(16) not null, server_default "running"
    - error_message: Text nullable
    - created_at: DateTime(timezone=True) server_default func.now()
    - completed_at: DateTime(timezone=True) nullable
    - Relationships: trades (list[BacktestTradeRecord]), equity_points (list[BacktestEquityRecord])

    `BacktestTradeRecord` (__tablename__ = "backtest_trades"):
    - id: UUID PK
    - backtest_id: UUID FK("backtests.id") not null, indexed
    - symbol: String(32) not null
    - action: String(16) not null
    - entry_time: DateTime(tz) not null
    - exit_time: DateTime(tz) nullable
    - entry_price: Numeric not null
    - exit_price: Numeric nullable
    - quantity: Numeric not null
    - pnl: Numeric nullable
    - fees: Numeric not null, server_default "0"
    - metadata_: mapped_column("metadata", JSONB, server_default="{}")

    `BacktestEquityRecord` (__tablename__ = "backtest_equity"):
    - Composite PK: (backtest_id, time)
    - backtest_id: UUID FK("backtests.id")
    - time: DateTime(tz)
    - equity: Numeric not null
    - drawdown: Numeric not null, server_default "0"
