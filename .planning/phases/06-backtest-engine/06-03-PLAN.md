    **1. Create `src/poseidon/backtest/walk_forward.py`:**

    ```python
    @dataclass
    class WalkForwardConfig:
        train_days: int = 252        # ~1 year IS
        validate_days: int = 63      # ~3 months (optional, for model strategies)
        test_days: int = 63          # ~3 months OOS
        step_days: int = 63          # roll forward by 1 quarter
        min_trades_per_oos: int = 30
        min_wfe: float = 0.50        # 50%

    @dataclass
    class WindowResult:
        window_index: int
        is_metrics: dict             # In-sample metrics from compute_metrics
        oos_metrics: dict            # Out-of-sample metrics from compute_metrics
        is_trade_count: int
        oos_trade_count: int

    @dataclass
    class WalkForwardResult:
        wfe: float
        passed: bool
        flags: list[str]
        per_window: list[WindowResult]
        aggregate_oos_metrics: dict   # Combined OOS metrics across all windows
        config: WalkForwardConfig
    ```

    `def compute_wfe(is_ann_return: float, oos_ann_return: float) -> float`:
    - If is_ann_return <= 0: return 0.0
    - Return oos_ann_return / is_ann_return

    Class `WalkForwardAnalyzer`:

    `def __init__(self, feature_engine: FeatureEngine, risk_engine: RiskEngine, cost_model: CostModel, initial_capital: float = 1_000_000.0)`:

    `def generate_windows(self, data_length: int, config: WalkForwardConfig) -> list[tuple[tuple[int, int], tuple[int, int]]]`:
    - Generate a list of (train_range, test_range) tuples where each range is (start_idx, end_idx) using exclusive-end semantics.
    - Start at index 0: train = [0, train_days), test = [train_days, train_days + test_days)
    - Step forward by step_days each iteration
    - Stop when test_end would exceed data_length
    - validate_days is reserved for model retraining (future use) -- for now, do NOT insert a validation gap between train and test. The validate window is conceptual for model strategies; for rule strategies, train IS test is directly adjacent.

    `def analyze(self, strategy: BaseStrategy, ohlcv: pd.DataFrame, config: WalkForwardConfig | None = None) -> WalkForwardResult`:
    1. Use default config if None
    2. Generate windows via `generate_windows(len(ohlcv), config)`
    3. For each window:
       a. Slice IS data: `ohlcv.iloc[train_start:train_end]`
       b. Slice OOS data: `ohlcv.iloc[test_start:test_end]`
       c. Run backtest on IS data: create `BacktestRunner(strategy, self.feature_engine, self.risk_engine, self.cost_model, self.initial_capital)` and call `runner.run(is_ohlcv)` -> get IS metrics
       d. Run backtest on OOS data: same runner setup, `runner.run(oos_ohlcv)` -> get OOS metrics
       e. Record WindowResult
    4. Compute aggregate OOS annualized return (from concatenated OOS equity curves or averaged per-window)
    5. Compute aggregate IS annualized return similarly
    6. `wfe = compute_wfe(aggregate_is_ann_return, aggregate_oos_ann_return)`
    7. Build flags list:
       - If wfe < config.min_wfe: append "wfe_below_threshold"
       - For each window where oos_trade_count < config.min_trades_per_oos: append f"insufficient_trades_window_{i}"
    8. `passed = wfe >= config.min_wfe and "insufficient_trades" not in any flag`
    9. Return WalkForwardResult
