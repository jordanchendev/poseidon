    **2. Create `src/poseidon/backtest/runner.py`:**

    Class `BacktestRunner`:

    ```python
    class BacktestRunner:
        def __init__(
            self,
            strategy: BaseStrategy,
            feature_engine: FeatureEngine,
            risk_engine: RiskEngine,
            cost_model: CostModel,
            initial_capital: float = 1_000_000.0,
        ):
            self.strategy = strategy
            self.feature_engine = feature_engine
            self.risk_engine = risk_engine
            self.cost_model = cost_model
            self.initial_capital = initial_capital
    ```

    `def run(self, ohlcv: pd.DataFrame) -> BacktestResult`:
    1. `features = self.feature_engine.compute_from_df(ohlcv)` -- SAME code path as live (BT-01)
    2. Determine warmup_bars: find the first row index where no feature columns have NaN. Skip all bars before this index.
    3. Create `portfolio = BacktestPortfolio(self.initial_capital, self.cost_model)`
    4. Bar-by-bar loop from warmup_bars to len(features):
       a. `features_slice = features.iloc[:i + 1]` -- no look-ahead
       b. `signals = self.strategy.evaluate(features_slice)` -- SAME code path (BT-01)
       c. For each signal in signals:
          - `signal = self.risk_engine.evaluate(signal, portfolio)` -- SAME code path (BT-01). Note: BacktestPortfolio is not a VirtualPortfolio subclass, so create a thin adapter or pass portfolio directly (the risk engine only calls `.open_position_count`, `.total_exposure()`, `.get_position()` -- implement these on BacktestPortfolio too).
          - If signal.status == PASSED: `portfolio.execute_fill(signal, features.iloc[i])`
       d. `portfolio.record_equity_point(features.iloc[i]["time"], features.iloc[i]["close"])`
    5. `metrics = compute_metrics(equity_series, portfolio.trades)`
    6. Return `BacktestResult(...)` with metrics, trades, equity_curve_length, status="completed"

    **CRITICAL for BT-01 compliance**: The runner must NOT contain any feature computation, strategy evaluation, or risk checking logic. It calls the exact same methods as the live `SignalPipeline`. The only backtest-specific logic is the bar-by-bar iteration and the portfolio fill simulation.

    **Risk engine adapter**: `RiskEngine.evaluate()` takes `VirtualPortfolio`. Create a simple adapter or duck-type: BacktestPortfolio must expose `open_position_count`, `total_exposure()`, and `get_position(market, symbol)` with the same signatures as VirtualPortfolio so the risk engine can call them without modification. This ensures the SAME risk engine code runs.
