1. **VolumeSMA** (name="volume_sma"):
   - Description: "Simple Moving Average of volume"
   - `compute(self, ohlcv, period=20, **kwargs) -> pd.Series`
   - Validate with `self._validate(ohlcv)`
   - Empty return: `pd.Series(dtype=float, name=f"volume_sma_{period}")`
   - Compute: `ohlcv["volume"].rolling(window=period).mean()`
   - Set `result.name = f"volume_sma_{period}"`

2. **VolumeRatio** (name="volume_ratio"):
   - Description: "Current volume relative to N-period average"
   - `compute(self, ohlcv, period=20, **kwargs) -> pd.Series`
   - Validate with `self._validate(ohlcv)`
   - Empty return: `pd.Series(dtype=float, name=f"volume_ratio_{period}")`
   - Compute: `ohlcv["volume"] / ohlcv["volume"].rolling(window=period).mean()`
   - Set `result.name = f"volume_ratio_{period}"`

3. **OBV** (name="obv"):
   - Description: "On-Balance Volume (cumulative signed volume)"
   - `compute(self, ohlcv, **kwargs) -> pd.Series`
   - Validate with `self._validate(ohlcv, min_rows=2)`
   - Empty return: `pd.Series(dtype=float, name="obv")`
   - Compute: `direction = np.sign(ohlcv["close"].diff())`, then `result = (ohlcv["volume"] * direction).cumsum()`
   - Set `result.name = "obv"`
   - Note: OBV has no period parameter, produces single column "obv"
