2. Update `src/poseidon/workers/cpu_tasks.py` — the existing BATCH_DAYS uses `"crypto_spot": 41` which is calibrated for 1h candles (1000 candles * 1h / 24h = ~41.7 days). For 5m candles: 1000 * 5min / 60 / 24 = ~3.47 days.

   The current batch selection logic is:
   ```python
   if interval == "1d" and market in BATCH_DAYS_DAILY:
       batch_days = BATCH_DAYS_DAILY[market]
   else:
       batch_days = BATCH_DAYS.get(market, 365)
   ```

   This means both 1h and 5m would use the same `BATCH_DAYS["crypto_spot"] = 41` days, but 5m needs a much smaller batch window. To handle this, add a new dict `BATCH_DAYS_5M` and update the batch selection logic.

   Add after the existing `BATCH_DAYS_DAILY` dict (after line 43 currently):
   ```python
   BATCH_DAYS_5M = {
       "crypto_spot": 3,        # CCXT 5m: ~3.47 days per 1000 candles
   }
   ```

   Update the batch selection logic in the `backfill_symbol` function. Find the block:
   ```python
   # Choose batch size based on market and interval
   if interval == "1d" and market in BATCH_DAYS_DAILY:
       batch_days = BATCH_DAYS_DAILY[market]
   else:
       batch_days = BATCH_DAYS.get(market, 365)
   ```

   Replace it with:
   ```python
   # Choose batch size based on market and interval
   if interval == "1d" and market in BATCH_DAYS_DAILY:
       batch_days = BATCH_DAYS_DAILY[market]
   elif interval == "5m" and market in BATCH_DAYS_5M:
       batch_days = BATCH_DAYS_5M[market]
   else:
       batch_days = BATCH_DAYS.get(market, 365)
   ```
