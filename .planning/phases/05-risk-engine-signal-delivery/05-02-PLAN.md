    ```python
    from abc import ABC, abstractmethod
    from dataclasses import dataclass
    from poseidon.signals.schemas import Signal

    @dataclass
    class RuleResult:
        passed: bool
        rule_name: str
        reason: str | None = None

    class BaseRule(ABC):
        name: str = ""
        enabled: bool = True

        @abstractmethod
        def check(self, signal: Signal, portfolio: "VirtualPortfolio") -> RuleResult:
            ...

        @abstractmethod
        def load_params(self, params: dict) -> None:
            ...
    ```

    **5 concrete rule files** — Each inherits BaseRule, implements `check()` and `load_params()`:

    1. **position_limit.py** — `PositionLimitRule`: Rejects if open positions count >= `max_positions` (default 10). `check()` counts non-closed positions in portfolio. `load_params(params)` reads `params.get("max_positions", 10)`.

    2. **loss_limit.py** — `LossLimitRule`: Rejects if number of consecutive REJECTED signals for this symbol exceeds `max_consecutive_rejects` (default 3). Per research recommendation: uses signal history, not live price P&L. `check()` queries recent signals for the symbol. `load_params(params)` reads `params.get("max_consecutive_rejects", 3)`.

    3. **frequency.py** — `FrequencyRule`: Rejects if symbol has >= `max_signals` signals within `time_window_hours` (default 24h). `check()` counts recent PASSED signals for the symbol. `load_params(params)` reads `params.get("max_signals", 5)` and `params.get("time_window_hours", 24)`.

    4. **confidence_threshold.py** — `ConfidenceThresholdRule`: Rejects if `signal.confidence < min_confidence` (default 0.5). Pure signal check, no portfolio needed. `load_params(params)` reads `params.get("min_confidence", 0.5)`.

    5. **leverage_cap.py** — `LeverageCapRule`: Rejects if total quantity_pct of open positions + new signal's quantity_pct exceeds `max_total_exposure` (default 1.0 = 100%). `check()` sums quantity_pct of non-closed positions. `load_params(params)` reads `params.get("max_total_exposure", 1.0)`.

    **src/poseidon/risk/portfolio.py** — `VirtualPortfolio`:
    - `__init__(self)`: Initialize `self.positions: dict[str, Any] = {}` where key is `f"{market}:{symbol}"`
    - `rebuild_from_db(self, db_session) -> None`: Query SignalRecord where status="passed", order by signal_time, replay via `_apply_signal()`. Clear positions first.
    - `_apply_signal(self, record: SignalRecord) -> None`: If action is long/short, create position entry. If action is close, remove position.
    - `open_position_count` property: count of non-closed positions
    - `get_position(self, market: str, symbol: str) -> dict | None`: lookup by key
    - `total_exposure(self) -> float`: sum of quantity_pct across open positions
    - `apply_signal(self, signal: Signal) -> None`: Public method for applying a signal to update in-memory state (called after risk check passes, before DB commit).
