    **src/poseidon/signals/delivery.py** — `class SignalDeliveryService`:
    - Constants: `STREAM_PREFIX = "poseidon:signals"`, `CONSUMER_GROUP = "thalassa"`, `RETENTION_DAYS = 7`
    - `__init__(self, redis_url: str)`: Create `self._redis = redis.from_url(redis_url, decode_responses=True)`. Import `redis` at module level.
    - `deliver(self, signal: Signal) -> str | None`: If `signal.status != SignalStatus.PASSED`, return None (rejected signals are NOT pushed to Redis). Otherwise:
      1. Build `stream_key = f"{self.STREAM_PREFIX}:{signal.market}"`
      2. Build `fields` dict with all required Signal data as strings:
         - `"id"`: `str(signal.id)`
         - `"action"`: `signal.action.value`
         - `"symbol"`: `signal.symbol`
         - `"market"`: `signal.market`
         - `"instrument"`: `signal.instrument.value`
         - `"confidence"`: `str(signal.confidence)`
         - `"signal_time"`: `signal.signal_time.isoformat()`
         - `"params"`: `json.dumps(signal.params)`
         - `"interval"`: `signal.interval`
         - Add `"quantity_pct"`: `str(signal.quantity_pct)` only if not None
         - Add `"strategy_id"`: `str(signal.strategy_id)` only if not None
         - Add `"model_id"`: `str(signal.model_id)` only if not None
      3. Call `self._ensure_consumer_group(stream_key)`
      4. Calculate `min_id = self._retention_minid()`
      5. Call `msg_id = self._redis.xadd(stream_key, fields, minid=min_id, approximate=True)`
      6. Return `msg_id`
    - `_ensure_consumer_group(self, stream_key: str) -> None`: Try `self._redis.xgroup_create(name=stream_key, groupname=self.CONSUMER_GROUP, id="0", mkstream=True)`. Catch `redis.ResponseError`, re-raise only if "BUSYGROUP" not in error message.
    - `_retention_minid(self) -> str`: `cutoff_ms = int((time.time() - self.RETENTION_DAYS * 86400) * 1000)` then return `f"{cutoff_ms}-0"`.
    - `trim_streams(self, markets: list[str]) -> dict[str, int]`: For each market, call `self._redis.xtrim(stream_key, minid=min_id, approximate=True)`. Return dict of market -> removed count. (For Celery Beat scheduled cleanup.)

Map `signal.action.value` -> `record.action`, `signal.instrument.value` -> `record.instrument`, `signal.status.value` -> `record.status`.
