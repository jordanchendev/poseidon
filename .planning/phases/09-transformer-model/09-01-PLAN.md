**3. TimeSeriesDataset (per D-02):**
A `torch.utils.data.Dataset` subclass that creates sliding windows from feature data.
- Constructor takes: `features` (np.ndarray of shape [n_samples, n_features]), `targets` (np.ndarray of shape [n_samples]), `lookback_window` (int, default 60)
- `__getitem__` returns a tuple: `(x, y)` where x is float32 tensor of shape [lookback_window, n_features] and y is int64 scalar tensor
- `__len__` returns `len(features) - lookback_window`
- Apply per-feature standardization (z-score normalization) using mean/std computed from the training features array. Store the `_mean` (shape [n_features]) and `_std` (shape [n_features]) as instance attributes so they can be reused at prediction time.

**4. PatchTST nn.Module (per D-01):**
Create a `PatchTST` class inheriting from `nn.Module`. Architecture:
- **Patching layer:** Reshape input [batch, lookback_window, n_features] into patches. Patch length default 16, stride default 8. Number of patches = `(lookback_window - patch_length) // stride + 1`. Each patch is flattened to `patch_length * n_features` then projected to `d_model` via a linear layer.
- **Positional encoding:** Learnable positional embeddings of shape [1, num_patches, d_model].
- **Transformer encoder:** Use `nn.TransformerEncoderLayer` + `nn.TransformerEncoder` with:
  - `d_model`: 64 (default)
  - `nhead`: 4 (default)
  - `num_layers`: 2 (default)
  - `dim_feedforward`: 128 (default)
  - `dropout`: 0.1 (default)
  - `batch_first=True`
- **Classification head:** `nn.Linear(d_model, 3)` for 3-class output (hold/long/short). Apply mean pooling across patch dimension before the head.
- `forward(x)` takes [batch, lookback_window, n_features], returns [batch, 3] logits.

**5. TransformerModel(BaseModel) (per D-01, D-04):**
Decorated with `@register_model`. Class attributes:
- `name = "transformer"`
- `description = "PatchTST Transformer for directional prediction"`

Instance attributes set in `__init__`:
- `self._model: PatchTST | None = None`
- `self._feature_list: list[str] = list(DEFAULT_FEATURES)`
- `self._device: str = "cuda" if torch.cuda.is_available() else "cpu"` (only if _HAS_TORCH)
- `self._mean: np.ndarray | None = None` (normalization mean)
- `self._std: np.ndarray | None = None` (normalization std)
- `self._lookback_window: int = 60`

**6. train() method (per D-03):**
- Raise RuntimeError if not _HAS_TORCH
- Merge default params with provided params: `merged = {**self.get_default_params(), **params}`
- Extract feature columns: `feature_cols = [c for c in self._feature_list if c in features.columns]`; update `self._feature_list = feature_cols`
- Drop rows with NaN from features (and align targets)
- Convert to numpy arrays
- Create TimeSeriesDataset with `lookback_window` from merged_params (default 60)
- Store `self._mean` and `self._std` from the dataset for prediction-time normalization
- Store `self._lookback_window` from merged_params
- Create DataLoader with `batch_size` from merged_params (default 32), `shuffle=True`
- Build PatchTST model with params: d_model, nhead, num_layers, dim_feedforward, dropout, patch_length, stride, lookback_window, n_features=len(feature_cols)
- Move model to `self._device`
- Use `torch.optim.AdamW` with `lr` from merged_params (default 1e-3), `weight_decay` from merged_params (default 1e-4)
- Use `torch.amp.GradScaler` and `torch.amp.autocast("cuda")` for mixed precision ONLY when device is "cuda"; on CPU, train without amp
- Training loop for `epochs` from merged_params (default 50):
  - Iterate DataLoader batches
  - Forward pass (with autocast if cuda), compute CrossEntropyLoss
  - Backward pass (with scaler if cuda)
  - Optimizer step
  - Track epoch loss
  - Log epoch loss every 10 epochs
  - **Early stopping:** Track best validation loss. If no improvement for `patience` epochs (default 10), break. Use last 20% of data as simple validation split.
- After training, compute training accuracy and return metrics dict: `{"accuracy": float, "n_samples": int, "n_features": int, "epochs_trained": int, "final_loss": float}`
- Store trained model in `self._model`

**7. predict() method (per D-04):**
- Raise RuntimeError if `self._model is None`
- Extract feature columns, drop NaN rows
- Normalize using stored `self._mean` and `self._std`
- Create sliding windows (same logic as TimeSeriesDataset but without targets)
- Run model in eval mode with `torch.no_grad()`, use autocast if cuda
- Apply softmax to get probabilities, take argmax for predictions, max probability for confidence
- Map prediction indices via LABEL_MAP
- Build result DataFrame with "prediction" and "confidence" columns
- Reindex to original features.index, fill missing with "hold" (matching XGBoost pattern)
- Note: The first `lookback_window` rows will be filled with "hold" since they lack full lookback context

**8. validate() method:**
- Same as predict but also compute accuracy and per-class accuracy against targets (matching XGBoost validate pattern)
- Return dict: `{"accuracy": float, "n_samples": int, "accuracy_hold": float, "accuracy_long": float, "accuracy_short": float}`

**9. save() method (per D-05):**
- Create directory, save `self._model.state_dict()` as `model.pt` via `torch.save()`
- Save `self._feature_list` as `features.json`
- Save metadata dict as `metadata.json` containing: model hyperparams (d_model, nhead, etc.), lookback_window, n_features, normalization mean/std as lists
- Log save location

**10. load() classmethod (per D-05):**
- Load `features.json`, `metadata.json`
- Reconstruct PatchTST model from metadata hyperparams
- Load state_dict from `model.pt` via `torch.load(path / "model.pt", map_location=device, weights_only=True)`
- Restore normalization mean/std from metadata
- Return configured TransformerModel instance
