# Plan 3: RuleStrategy + DSL condition engine

<objective>
Implement the JSON DSL condition engine and RuleStrategy. The DSL engine provides recursive evaluation of all/any/none combinator trees with a registry of leaf condition evaluators (6 predefined types). RuleStrategy parses DSL JSON documents, evaluates conditions row-by-row against a feature DataFrame, and produces Signal objects for rows where conditions are met.

Purpose: This enables rule-based trading strategies defined as JSON documents (generated by Thalassa's LLM from natural language). Combined with ModelStrategy (Plan 02), this completes the strategy layer's two concrete implementations under the unified BaseStrategy interface.

Output: `strategies/dsl/` package (schema, conditions, executor), `strategies/rule_strategy.py`, tests for both DSL engine and RuleStrategy.
</objective>

**2. `src/poseidon/strategies/dsl/schema.py`:**
Pydantic models for DSL JSON validation. The top-level document is `RuleConfig`. Each rule entry is `RuleEntry` containing a condition tree, an action string, and optional quantity_pct.

```python
"""DSL JSON schema -- Pydantic models for rule-based strategy definitions.

Validates the JSON structure received from Thalassa (LLM-generated or hand-written).
The condition field is kept as a raw dict because its structure is recursive
(all/any/none trees), validated at evaluation time by the executor.
"""

from pydantic import BaseModel, Field


class RuleEntry(BaseModel):
    """A single rule: condition tree + action to take if condition is met."""
    condition: dict  # Recursive tree -- validated by executor at eval time
    action: str      # "long", "short", "close"
    quantity_pct: float | None = Field(None, ge=0.0, le=1.0)
    confidence: float = Field(1.0, ge=0.0, le=1.0)  # Default confidence for rule-based


class RuleConfig(BaseModel):
    """Top-level DSL document for a rule-based strategy."""
    name: str
    description: str = ""
    symbol: str
    market: str
    interval: str = "1d"
    rules: list[RuleEntry] = Field(..., min_length=1)
```

**3. `src/poseidon/strategies/dsl/conditions.py`:**
Registry of leaf condition evaluator functions. Each evaluator takes `(condition: dict, features: pd.DataFrame, row_idx: int) -> bool`. Also contains the `resolve_column_name(indicator, params)` helper.

6 predefined condition evaluators:
- `indicator_above`: `features.iloc[row_idx][col] > threshold`
- `indicator_below`: `features.iloc[row_idx][col] < threshold`
- `price_crosses`: Compare current row's close vs indicator value relative to previous row (direction: "up", "down", "touches_from_above", "touches_from_below")
- `indicator_crosses`: Compare fast vs slow indicator -- current row fast > slow AND previous row fast <= slow (direction "up"), or reverse for "down"
- `price_change_pct`: Check `return_1d` column against threshold with direction ("up" means return > threshold, "down" means return < -threshold)
- `volume_spike`: Check if `volume` > `multiplier * mean(volume over last period rows)`

Column name resolution convention:
- `resolve_column_name("rsi", {"period": 14})` returns `"rsi_14"`
- `resolve_column_name("sma", {"period": 60})` returns `"sma_60"`
- `resolve_column_name("ma", {"period": 60})` returns `"sma_60"` (ma is alias for sma)
- `resolve_column_name("macd", {})` returns `"macd_line"`
- `resolve_column_name("price_vs_ma", {"period": 60})` is handled inline by the condition evaluator (compares close to sma_60)

The registry is a simple dict: `CONDITION_REGISTRY: dict[str, Callable] = {}` with a `register_condition` decorator.

```python
CONDITION_REGISTRY: dict[str, Callable] = {}

def register_condition(name: str):
    def decorator(fn):
        CONDITION_REGISTRY[name] = fn
        return fn
    return decorator
```

**4. `src/poseidon/strategies/dsl/executor.py`:**
Recursive tree evaluator. Handles `all`, `any`, `none` combinator nodes and dispatches leaf nodes to `CONDITION_REGISTRY`.

```python
def evaluate_condition(
    condition: dict,
    features: pd.DataFrame,
    row_idx: int,
    *,
    max_depth: int = 10,
    _current_depth: int = 0,
) -> bool:
    """Recursively evaluate a DSL condition tree against a feature DataFrame row.

    Args:
        condition: Condition dict -- either a combinator (all/any/none with children)
                   or a leaf (type + parameters).
        features: Wide DataFrame from FeatureEngine.
        row_idx: Which row to evaluate (integer positional index).
        max_depth: Maximum nesting depth to prevent infinite recursion.
        _current_depth: Internal depth tracker.

    Returns:
        True if the condition is satisfied for the given row.

    Raises:
        ValueError: If condition type is unknown or max depth exceeded.
    """
    if _current_depth > max_depth:
        raise ValueError(f"DSL condition nesting exceeds max depth ({max_depth})")

    next_depth = _current_depth + 1

    # Combinator nodes
    if "all" in condition:
        return all(
            evaluate_condition(c, features, row_idx, max_depth=max_depth, _current_depth=next_depth)
            for c in condition["all"]
        )
    if "any" in condition:
        return any(
            evaluate_condition(c, features, row_idx, max_depth=max_depth, _current_depth=next_depth)
            for c in condition["any"]
        )
    if "none" in condition:
        return not any(
            evaluate_condition(c, features, row_idx, max_depth=max_depth, _current_depth=next_depth)
            for c in condition["none"]
        )

    # Leaf node -- dispatch to registered condition evaluator
    cond_type = condition.get("type")
    if cond_type not in CONDITION_REGISTRY:
        raise ValueError(
            f"Unknown condition type: '{cond_type}'. "
            f"Available: {list(CONDITION_REGISTRY.keys())}"
        )
    return CONDITION_REGISTRY[cond_type](condition, features, row_idx)
```

```python
"""RuleStrategy -- evaluates JSON DSL conditions against feature data.

Data flow:
    DSL JSON (from Thalassa or manual) -> RuleConfig (validated)
        -> For each row in features DataFrame:
            -> For each rule in config:
                -> evaluate_condition(rule.condition, features, row_idx)
                -> If True: emit Signal with rule's action and quantity_pct

RuleStrategy evaluates the LAST row by default (live mode). For backtesting,
the caller iterates rows and passes single-row DataFrames or specifies row_idx.
"""

import logging
from datetime import datetime
from uuid import UUID, uuid4

import pandas as pd

from poseidon.signals.schemas import InstrumentType, Signal, SignalAction
from poseidon.strategies.base import BaseStrategy, StrategyType
from poseidon.strategies.dsl.executor import evaluate_condition
from poseidon.strategies.dsl.schema import RuleConfig, RuleEntry

logger = logging.getLogger(__name__)


class RuleStrategy(BaseStrategy):
    """Strategy that evaluates JSON DSL conditions against feature data.

    Parses a DSL JSON document (via RuleConfig) and evaluates each rule's
    condition tree against the feature DataFrame. Produces Signal objects
    for rules whose conditions are met.
    """

    strategy_type = StrategyType.RULE

    def __init__(
        self,
        *,
        config: RuleConfig | dict,
        instrument: InstrumentType = InstrumentType.SPOT,
        strategy_id: UUID | None = None,
    ):
        # Accept either a RuleConfig or a raw dict (will be validated)
        if isinstance(config, dict):
            config = RuleConfig(**config)
        self.config = config
        self.name = config.name
        self.symbol = config.symbol
        self.market = config.market
        self.interval = config.interval
        self.instrument = instrument
        self.strategy_id = strategy_id or uuid4()

    def evaluate(self, features: pd.DataFrame) -> list[Signal]:
        """Evaluate all rules against the last row of the feature DataFrame.

        Args:
            features: Wide DataFrame from FeatureEngine.

        Returns:
            List of Signal objects for rules whose conditions are met.
            Empty list if no rules trigger.
        """
        if features.empty:
            return []

        # Evaluate against the last row (most recent data point)
        row_idx = len(features) - 1
        signals: list[Signal] = []

        for rule in self.config.rules:
            try:
                triggered = evaluate_condition(rule.condition, features, row_idx)
            except (ValueError, KeyError) as e:
                logger.warning(
                    "RuleStrategy '%s' rule evaluation error: %s", self.name, e
                )
                continue

            if triggered:
                signal_time = (
                    features.index[row_idx]
                    if isinstance(features.index[row_idx], datetime)
                    else datetime.utcnow()
                )
                signals.append(
                    Signal(
                        strategy_id=self.strategy_id,
                        symbol=self.symbol,
                        market=self.market,
                        instrument=self.instrument,
                        action=SignalAction(rule.action),
                        confidence=rule.confidence,
                        quantity_pct=rule.quantity_pct,
                        interval=self.interval,
                        signal_time=signal_time,
                    )
                )

        logger.info(
            "RuleStrategy '%s' evaluated %d rules -> %d signals",
            self.name,
            len(self.config.rules),
            len(signals),
        )
        return signals

    def validate_config(self) -> bool:
        """Validate that the strategy has rules and required fields.

        Returns:
            True if valid.

        Raises:
            ValueError: If rules are empty or symbol/market missing.
        """
        if not self.config.rules:
            raise ValueError("RuleStrategy requires at least one rule")
        if not self.symbol:
            raise ValueError("RuleStrategy requires a symbol")
        if not self.market:
            raise ValueError("RuleStrategy requires a market")
        return True
```
