<objective>
Build per-regime Optuna parameter search and the outperformance gate that decides whether regime routing is enabled or disabled. The search varies only min_votes and position_pct per regime (D-04, D-06). The gate compares regime-routed vs static VotingStrategy composite_score on holdout data and auto-disables if regime routing does not strictly outperform (D-07, D-08, D-09).

Purpose: Complete the gated regime classification system -- the search finds optimal per-regime params, the gate enforces the "prove it works or turn it off" principle.
Output: regime_search.py, regime_gate.py, test_regime_search.py with passing tests.
</objective>
